A Rex extension for Claude Code Install

Your CLAUDE.md learns from every session.

When you step away, Amber reads what happened and marks up your CLAUDE.md with what's worth keeping. You decide what stays.

Turn it on in Rex See how it works

You work as usual. You step away. It takes notes.

  1. Now

    Nothing changes while you're with your agent. Amber only pays attention in projects that have a .claude/CLAUDE.md.

  2. After 10 quiet minutes

    Claude Sonnet reads the part of the conversation it hasn't seen yet, in the background, on your own Claude account.

  3. Whenever you like

    Up to three suggestions, often none. Type /review-suggestions in Claude Code.

It suggests. It never writes.

Every suggestion is a plain file in your repo, with the moment it came from. Keep what helps, reject what doesn't, and it won't ask again.

No magic. Just Rex and your Claude.

It runs inside Rex

Rex knows what every terminal pane is doing, including when Claude Code is working and when it's waiting for you. Amber is a small script for Rex that listens to those signals.

It reviews with your Claude

Each review runs Claude Code in the background, with Claude Sonnet by default, on your own account. It counts toward your plan or API usage like any other session. To keep that small, it only runs after ten quiet minutes, and only reads what's new.

You know what it sends

The new part of the conversation, Claude's own notes about the project, and the files it checks in your repo go to Claude, through your claude, the same way your sessions do. Every suggestion stays in your repo.

Teach your agent once, not every morning.

Amber lives in Rex's config folder. Three commands, nothing hidden.

~ — Rex 
# download it next to Rex's config
$ git clone https://github.com/benhid/rex-amber ~/.config/rex/amber
# load it
$ echo 'require("amber.action")' >> ~/.config/rex/init.lua
$ rex config reload

Then run Enable Amber from Rex's command palette.

enable
Enable Amber
Change Keybinding ⌘↩ Action ↩
